# Single-Service Example

This example demonstrates exposing a single local application (e.g., Next.js, Vite, React, Vue, or Svelte running on `localhost:3000`) using PORTA.

## How to Run

1. Start your local web server:
   ```bash
   npm run dev # Running on localhost:3000
   ```
2. Start PORTA in this directory:
   ```bash
   porta start
   ```
3. Open the generated `https://<slug>.trycloudflare.com` URL in any browser or on a mobile device.
