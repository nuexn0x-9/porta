# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The PORTA maintainers take security seriously. If you discover a security vulnerability in PORTA, please follow responsible disclosure guidelines.

**Please do NOT file a public issue.**

Instead, please report security issues privately via:
- GitHub Security Advisory tab on the repository: [https://github.com/nuexn0x-9/porta/security/advisories](https://github.com/nuexn0x-9/porta/security/advisories)
- Or contact the maintainers directly via repository channels.

### Information to Include in Your Report:
- Type of issue (e.g., SSRF bypass, authentication timing flaw, log leakage)
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability
- Affected operating system and environment
- Any proposed mitigations or fixes

### Our Commitment:
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a regular status update on the fix progress.
- Once fixed, a security advisory and patched release will be published.
