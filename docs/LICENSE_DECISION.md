# LICENSE DECISION & EVALUATION

**Project:** PORTA  
**Version:** v1.0.0 (MVP)  

---

## 1. Evaluation of Open Source License Options

| License | Type | Strengths | Weaknesses | Fit for PORTA |
| :--- | :--- | :--- | :--- | :--- |
| **Apache-2.0** | Permissive | • Explicit patent grant protects users and contributors.<br>• Clear trademark clause protects project identity.<br>• Highly enterprise-friendly. | Slightly longer license text. | **RECOMMENDED (Primary)** |
| **MIT** | Permissive | • Extremely short and universally recognized.<br>• Zero friction for developers. | Lacks explicit patent grant clauses. | **ALTERNATIVE** |
| **GPL-3.0** | Copyleft | • Strong viral protection ensures derivative works stay open source. | Restricts adoption in enterprise and commercial plugin environments. | **NOT RECOMMENDED** |

---

## 2. Decision & Recommendation

**Selected License:** **Apache License, Version 2.0**

### Rationale:
1. Developer tools benefit greatly from corporate and enterprise adoption without legal friction.
2. The explicit patent grant in Apache 2.0 protects developers and contributors from patent trolling.
3. The trademark clause protects the **PORTA** brand from unauthorized commercial rebranding while allowing unrestricted code reuse.
